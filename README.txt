Burbank LMS WordPress plugin.

== Description ==

The Burbank LMS plugin foundation. Feature work belongs in `src/` and is registered through the loader.

== Installation ==

Install a built Burbank LMS plugin ZIP in WordPress and activate it. Do not install a source checkout without its Composer dependencies and built assets.
